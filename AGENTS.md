# AGENTS.md

A personal grab-bag of debugging notes and tutorial walkthroughs (Docker, Ruby, Slidev, VS Code, Kintone scripts, etc.). Not a software product. Most changes are markdown edits inside topic folders.


## Layout

Each top-level folder is a topic notebook with its own `<Topic>.md` writeup. The root `README.md` is a tree generated by [markdown-notes-tree](https://github.com/cmorten/markdown-notes-tree); regenerate it after adding or renaming folders.


## Stack

* No package manager. `_config.yml` indicates the repo can be served as a Jekyll site, but day-to-day work is just markdown editing.


## Conventions

* Folder names use `Snake_Case_Or_Spaces` to match the historical style; keep new folders consistent with neighbors rather than imposing a new scheme.
* When adding or renaming notes, regenerate the root `README.md` tree so links stay accurate.
* Never use en-dash or em-dash; always use a plain hyphen (`-`) instead.


## Git commits

* Never add a `Co-Authored-By` trailer.
* Use the `ai-commit` skill to draft messages.
